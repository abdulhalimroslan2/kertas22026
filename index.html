⚡ Konfigurasi Supabase Cloud Database

Sambungkan database Supabase (Percuma) agar kiraan had muat turun dikuatkuasakan secara dalam talian (Cloud-based) dan 100% kalis-bypass.

💡

Langkah Setup Supabase (1 Minit Sahaja):

  1. Buka supabase.com dan daftar/cipta projek percuma.
  2. Pergi ke menu SQL Editor, salin isi fail schema.sql dalam projek ini, dan klik Run.
  3. Pergi ke Project Settings ➔ API, salin Project URL & anon public key ke ruangan di atas.
